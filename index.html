opencode-selfhost

Self-hosted OpenCode server in Docker behind a Caddy reverse proxy with automatic HTTPS. Only the API endpoints required by opencode attach are exposed.

Docker Caddy OpenCode HTTPS Watchtower

Quick start

git clone https://github.com/danifernandezs/opencode-selfhost.git
cd opencode-selfhost

cp .env.example .env
cp opencode.json.example opencode.json

# Edit .env and opencode.json with your config
docker compose up -d

Connect from any machine

opencode attach https://oc.yourdomain.com \
  --password your-server-password \
  --dir /projects/my-project

Features

  • Automatic TLS via Let's Encrypt (Caddy)
  • API-only exposure — web UI blocked by default
  • Multi-arch Docker image (amd64 + arm64)
  • Auto-updates via Watchtower
  • Data persistence across rebuilds
